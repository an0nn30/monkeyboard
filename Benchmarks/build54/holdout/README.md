# Build 54 independently authored paired-message holdout

This cohort was written from scratch in a second authoring pass before the author saw any model predictions. All 138 messages are simulated everyday texts. Each reference has a noisy and a clean input. Seventy-five noisy messages have two marked errors. The remaining 63 have one. The cases include ordinary typing slips, contextually wrong valid words, and omitted spaces. Case, shorthand and punctuation belong to the intended reference.

The JSON array in `cases.json` uses the same schema as the build 53 holdout. Each row has an `id`, shared `pair_id`, `split`, `kind`, `source`, `source_id`, `typed`, `expected`, `protected`, and `edits`. Source IDs are one-based line numbers in `authored.txt`. The clean and noisy forms annotate the same 38 name occurrences and 29 slang or shorthand occurrences apiece. Name spellings include 20 lowercase, 17 capitalized and one all-caps occurrence on each side. Each protected record gives the case-sensitive literal spelling and zero-based whitespace indices in the typed and expected texts. Each edit gives its surface text and start index on each side. `mixed` signifies two different categories of error.

The exact-overlap check excludes both sides of each new pair from intersection with the desktop typo corpus, earlier fixture sources, build 53's holdout, build 53's development and desktop-check inputs, the bundled Tatoeba corpus, UCI ham, Taskmaster training utterances, and the enumerated local phrase/practice texts. Normalization follows the build 53 fixture implementation. An additional pairwise check compares word sequences within the new references and against all build 53 holdout references. It uses the ratio from Python's `difflib.SequenceMatcher` on normalized word lists with `autojunk=False`. Maximum ratios were 0.417 within this set and 0.632 against build 53. These checks do not detect all possible paraphrases.

Run `python3 Benchmarks/build54/holdout/freeze.py` from the project root to reproduce the verification, including annotation indices, checksums, overlap counts and word-sequence similarity. The script accepts paths for the original desktop file, Taskmaster utterances and pinned UCI archive. It reuses only the annotation and source-audit code from build 53. To verify the distributed JSON without external source files, compare `shasum -a 256 cases.json` with the digest in `freeze.json`.
