# Residual name protection

The broad gate checks both ends of a new residual suggestion. The strong gate checks the original spelling alone before a legacy lexical substitution. Both use case-independent lookup so a lowercase sentence-opening name receives the same evidence as the capitalized spelling.

The trainer measures medial capitalization across distinct references in the existing desktop training split and the English CC0 corpus. It excludes sentence-opening tokens from these counts. Two independent inputs provide priors for sparse names: the macOS proper-name dictionary and the preferred medial display surfaces learned by surface31. Each of the four evidence groups receives its estimated prior probability from observed word types. Individual title/lowercase counts update this prior. A separate reference partition chooses the decision threshold, charging five false name labels per missed capitalized token. Selecting on case provides a proxy for proper-name usage, including some places and calendar terms. The older surface31 display table was trained on the broader desktop training partition.

The broad inventory contains 1,851 spellings. The strong inventory requires high-confidence casing or proper-name dictionary support, excludes strings shorter than four letters, and excludes original spellings observed to disappear in a training S:/C: pair. It retains 1,239 spellings. The two read-only tables contain 24,720 bytes of sorted 64-bit word hashes. The original-only gate could veto one of 21,010 desktop calibration repairs; the first original-only candidate, before the short-spelling and observed-typo filters, would veto 100. This measures potential token-level vetoes against gold corrections rather than edits committed by the keyboard. None of the five historical SMS development replays had a changed input matching the strong original-only inventory. The broad gate operates only on new residual proposals.

Reproduce with `python3 keyboard-engine/training/name54.py "$PAIRED"` on macOS or pass the dictionary path using `--propernames`. The metadata includes the dictionary SHA-256. The trainer reads the existing surface31 resource and local corpora. Build 53 and 54 final fixtures are excluded from fitting, calibration, and inspection.
